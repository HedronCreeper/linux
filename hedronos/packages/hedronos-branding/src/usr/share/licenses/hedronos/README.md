# Artwork licence

All HedronOS artwork in this package (the four wallpapers, the logo, the Plymouth drawing and
the SDDM/KDE theme assets) is dedicated to the public domain under **CC0-1.0**, so you may
copy, remix and redistribute it without attribution — including inside your own spin of this
distro. The *code* in this repository is MIT; see `hedronos/LICENSE`.

The geometry in every wallpaper is the same stellated octahedron (two interlocking tetrahedra)
with a different palette and rotation. They are SVG on purpose: one source file scales from a
1200x800 handheld panel to 4K, costs a few KiB in RAM, and can be blurred by the compositor for
the lock screen without a decode step.
